# Demo Flow (for judges)

1. Open the app → **Demo Login** (no account needed).
2. Dashboard — attention stats, recent analyses, deadlines, activity.
3. Open the seeded analysis: *Bengaluru Metro Corridor-7 — Civil Works Package C4*.
4. Overview → readiness 76%, BID WITH CONDITIONS stamp, score breakdown.
5. Requirements → filter to FAIL → *Similar completed projects* (2 of 3) → **Open evidence**.
6. Evidence Viewer → tender source page vs company evidence, side by side.
7. Risks → HIGH liquidated-damages / timeline risks with tender clause + page.
8. Decision → large stamp, readiness ring, what passes/blocks/needs review, **Export report**.
9. Action Plan → tick off tasks (persists).
10. New Analysis → upload any tender PDF → select company + evidence → **Analyze Tender** →
    watch the 9-stage progress → real AI result.
